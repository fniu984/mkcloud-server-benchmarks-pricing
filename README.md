# mkcloud 服务器测评：广港/沪港/沪美三线实测数据、全套餐价格与优惠码整理

搜"mkcloud 服务器测评"的人，大多是被它家的专线标签吸引：2023 年成立的国人商家，主营广港 IEPL、沪日/沪美 IPLC 和上云互联优化专线，定位是给跨境电商、出海团队用的合规专线 VPS。但官网宣传终归是宣传，这篇文章把第三方实测数据、当前在售的全部套餐价格、能用的优惠码和购买前必须知道限制（实名、省级白名单、退款政策）一次说清，帮你判断这钱花得值不值。

## MKCloud 是谁：一家只做跨境专线的国人商家

MKCloud（mkcloud.net）2023 年创立，规模不算大，产品线非常集中：不做普通建站 VPS，也不卖虚拟主机，只做"国内入口 + 海外出口"的专线云服务器。目前官网上挂着的产品方向包括广东-香港 IEPL、上海-日本 IPLC、上海-香港 IPLC、上海-美国 IPLC、福建-香港高防 IPLC、上海 CN2，以及两类"上云互联优化入口（IXP）"专线。

几个商家层面的事实，购买前值得知道：

- 机器是 KVM 虚拟化，入口走国内大厂机房（如腾讯广州八线 BGP、上海电信），出口在香港或美国 BGP，双端各配一个独立 IPv4；
- 只支持支付宝付款，下单可选月付、季付、年付等周期，官方知识库举例的套餐季付价正好是月付×3，说明长周期未必自动打折，价格以结算页为准；
- 有 Telegram 通知群和客服账号，测评社区的反馈是：在线客服高峰期响应慢，着急的问题建议直接走工单，技术问题的处理速度反而更快。

它不是机场，卖的是正经云服务器——这个区别后面会反复出现。

## 先搞懂三种线路：IEPL、IPLC 和上云互联（IXP）

MKCloud 的套餐名字里都是线路缩写，先花一分钟分清它们，后面看价格表才不晕。

**IEPL / IPLC** 是传统意义上的"专线"：国内入口和海外出口之间走点对点物理专线，不过公网，速度和延迟受晚高峰影响小。广港 IEPL 走广东入口，沪日、沪美 IPLC 从上海电信入口进。这类产品入口对所有公网 IP 开放，缺点是贵——专线带宽是稀缺资源。

**上云互联优化入口（IXP）** 是它家的性价比产品线。入口 IP 只在大厂内网（IX）内宣告，换句话说，只有阿里云、腾讯云、百度云、火山云、华为云等云厂 BGP 网络能连进来，三大运营商的公网直连是不通的。所以它适合"国内云服务器做前置 + MKCloud 做出海出口"的玩法，比如你在腾讯云上海有台轻量服务器，把它当跳板接 IXP 专线。没有云厂机器的话，这条线对你没意义。

还有两个计费细节几乎所有套餐通用：流量按上行+下行**双向统计**，每月额度用完会停机，可以自助购买流量重置或工单补差价升级；所有专线产品禁止机场、回国等用途，检测到会清退不退款。

## 实测数据：延迟、跑分和流媒体解锁

第三方对 MKCloud 有过好几轮完整测试，这里汇总能查到数据的三次：VPS.DANCE 的广港 IEPL 测评、虎窝博客的沪港 IXP 2TB 测评，以及多篇沪日/沪美测评。以下数据均来自这些公开测试，不是本站实测。

### 广州入口延迟：三网 33~38ms，端内 1~2ms

广港 IEPL 测评里，广州入口的 TCP ping 平均值为：电信 34ms、联通 33ms、移动 38ms。这个数字是"你家到国内入口"的延迟；入口到香港出口之间的专线程（所谓"端内"）官方标 1~2ms，实测在 2~4ms。合计起来，华南用户拿到手的到港延迟基本在 35~40ms 区间，比走公网的普通香港 VPS 晚高峰动辄 80~150ms 的表现稳定得多。

沪港 IXP 测评给出的出口方向延迟为 20.7~23.7ms（上海入口到香港各测速点），多线程抖动不超过 0.2ms，线路质量相当干净。沪美 IPLC 是物理专线里最远的一条，官方页面标注端内延迟 124~134ms，属于美线的正常物理水平。

### 机器性能：EPYC 平台，跑分在及格线以上

- 广港 IEPL-500GB 套餐：AMD EPYC 7402P 平台，单核 Geekbench 6 跑分 1363，磁盘平均写入约 304MB/s；
- 沪港 IXP-2TB 套餐：EPYC Rome 平台，Geekbench 6 单核 1244 / 多核 2264，4K 随机读 240MB/s，128K 顺序读 458MB/s。

对跑业务程序来说，这个性能不是瓶颈，瓶颈永远在流量和带宽上。

### 带宽与流媒体解锁：500M 口能跑满，IP 风险评分低

沪港 IXP 2TB 套餐标 500M 峰值带宽，实测到香港 HKBN 测速点跑出 483/451Mbps，接近跑满标称值；255Mbps 档位的广港套餐在单线程国际测速中也稳定在 130Mbps 上下。

出口 IP 段归属 Nearoute Limited（AS147293），多数风险数据库评分很低（Scamalytics 欺诈分 0），原生广播 IP，流媒体解锁情况：Disney+、Netflix（港区）、TikTok（新加坡区）、YouTube 均原生解锁；ChatGPT 网页端不行，只有 App 能用。另外，测试显示 25 端口出站被阻断，想拿来发邮件的不用考虑了。

不过要提醒一句：早年第三方对他家**美国普通 VPS**（非专线产品）的评价是国内访问稳定性一般、速度平平，亮点是无限 DDoS 防御。现在的主力产品是专线线，但选美国方向时别把两条产品线混为一谈。

## 购买前必须知道的三件事

### 实名认证和省级白名单

所有专线产品需要**中国手机号+身份证**实名认证，匿名买不了。开通后产品启用省级白名单，只允许你选定的那个省份的 IP 连入，防止被拿去做机场——省份可以在后台随时切换。人经常跨省出差的，记得切换白名单，否则连不上入口别急着怪线路。

### 退款政策是"24 小时+质量问题"

服务条款写得很直白：开通后 24 小时内，能拿出具体质量问题证据（延迟数据、速度数据、测试截图）才可能退款，由商家审核判断，不是无理由试用。而且**开通后不支持更换到其他地域的产品**。所以下单前先把入口延迟测明白：拿同机房云主机 ping 一下入口 IP，比买完再扯皮省事得多。A/B 测速截图留好，万一要走退款流程，这些就是全部凭证。

### 售后靠工单，活动信息在 Telegram

售后渠道是工单+TG 群，官方客服账号在官网"联系我们"页面。社区反馈是高峰期在线客服经常排不上，工单回复几小时内居多，技术问题处理得比较快。买之前不妨先进通知群潜水几天，看商家活动节奏和故障公告，比看任何测评都直观。

## 谁适合买，谁别买

适合的情况：

- 华南做跨境电商，店铺后台、素材上传对晚高峰稳定性敏感，受不了普通港 VPS 的公网抖动；
- 已经有阿里云/腾讯云等国内云服务器，想加一条便宜的出海出口，广港/沪港 IXP 直接对上需求；
- 做日本、美国方向的持续传输，沪日/沪美 IPLC 独享带宽按速率付费，比共享峰值可预期。

不建议的情况：

- 想匿名购买、拒绝实名认证的，这条线直接排除；
- 只有几百 MB 日流量的轻度用途，普通 CN2 VPS 一年几百块更划算；
- 想做机场、流量转发中继的，条款明确清退不退款，别试；
- 需要 25 端口发信的自建邮件场景。

## 常见问题

**MKCloud 的"专线 VPS"和普通香港 VPS 有什么区别？**

普通港 VPS 的流量走公网（CN2 GIA 也只是路由优化），晚高峰拥塞时延迟和丢包会明显波动。MKCloud 的专线在国内入口和海外出口之间走物理专线程，端内 1~2ms 且不受公网拥塞影响，实测三网到广州入口 33~38ms。代价是价格高、要实名、有白名单限制。

**流量双向计费是什么意思？**

上行和下行加在一起算。比如 2TB 档位，一个月内上传 1.2TB+下载 0.8TB 就到顶了，之后停机，可购买流量重置或升级套餐。评估流量需求时按双向估算，别只算下载。

**支持哪些付款和计费周期？**
